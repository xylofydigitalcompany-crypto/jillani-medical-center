A modern and responsive landing page for **Jillani Medical Center**. Developed to provide a professional digital presence for the healthcare facility.

## 🏥 Features
*   **Medical Services Overview:** Clear sections for diagnostics and departments.
*   **Online Inquiries:** Built-in form structure for patient appointments.

*   **Clean UI:** Professional design focused on healthcare trust.
